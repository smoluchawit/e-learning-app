01

Treści edukacyjne

Sekcje z teorią na temat Kotlina.

1. Deklaracja funkcji

W Kotlinie funkcję deklarujemy słowem kluczowym fun. Najprostsza funkcja wygląda tak: 

fun przywitaj() {
    println("Cześć!")
}

2. Parametry funkcji

Parametry podajemy w nawiasach w formacie nazwa: Typ. Możemy też nadać im wartości domyślne. 

fun przywitaj(imie: String, wiek: Int = 18) {
    println("Cześć $imie, masz $wiek lat!")
}

3. Wartość zwracana

Typ zwracany podajemy po dwukropku za nawiasem. Używamy słowa return. Jeśli funkcja nic nie zwraca — zwraca Unit (można pominąć). 

fun dodaj(a: Int, b: Int): Int {
    return a + b
}

4. Funkcja jednolinijkowa

Jeśli funkcja zwraca tylko jedno wyrażenie, możemy skrócić zapis używając =. 

fun dodaj(a: Int, b: Int): Int = a + b
